## 我有知識庫，你有資料嗎？

知識庫架好的那天早上，我心情非常好。

架構簡單到有點不好意思說出口：一個 mcp-memory-service，加上一支我自己寫的 Slack bot。選 Slack 沒什麼高深的理由——公司本來就在用，不用叫大家再裝一個 app。

至於 AI？還沒。這一版只做一件事：收到問題，去知識庫搜尋，把找到的筆記原封不動貼回來。

    A[客服在 Slack 發問] --> B[我的 Slack bot]
    B --> C[mcp-memory-service<br>搜尋相關筆記]
    C --> D[把命中的筆記<br>原封不動貼回頻道]
{{< /mermaid >}}

中午前，它動了。我塞了兩筆測試資料，在頻道裡問了一句，bot 乖乖地把筆記貼了出來。

<br>

```
搜尋「分潤設定」→ 命中 1 筆，已回貼
```

<br>

我看著那行 log，有種「我上線了一個產品」的錯覺，甚至開始想年底考績會不會很好看。

然後我打開知識庫，準備欣賞我的成果。

裡面有兩筆。

就是我剛剛塞的那兩筆測試資料。

<br>

> **我**：⋯⋯所以，我現在要放什麼進去？

<br>

對啊，放什麼？

我回頭去翻公司的文件——要嘛沒有，要嘛是三年前寫的，內容跟現在的系統對不上。真正有用的東西全在前輩腦子裡，而前輩正在忙。

我當時完全沒有「先盤點、再決定放什麼」的概念。我只有一個很急的念頭：**它不能是空的**。

於是我開始狂塞。

會議記錄、Slack 上撈到的對話、我自己的隨手筆記、那份過時的舊文件——看到什麼塞什麼，先求有再求好。塞的時候我甚至有點爽，看著筆數往上跳，覺得自己在建設什麼了不起的東西。

<br>

```
memory count: 2 → 47
```

<br>

現在回頭看，這 47 筆就是後面所有惡夢的起點。

**學到一課**：架服務只花一個早上，生內容要花一輩子。

---

## 明明存過，怎麼就是搜不到？

塞完的隔天，我開始自己測。

我挑了一筆我確定塞進去的知識，換個問法問 bot。

<br>

> **我**：客戶的分潤要怎麼設定？
>
> **bot**：（沒有回應）

<br>

蛤？

我不信邪，換了五種問法，中了兩次。剩下三次，bot 安靜得像沒上班。

我把那筆知識撈出來看，才發現問題：那不是一筆知識，那是一篇文章。我當初圖方便，把整份會議記錄一整段貼進去，裡面同時講了分潤設定、權限開通、還有某個跟主題無關的閒聊。

一筆記憶裡塞了五件事，難怪它不知道自己在講什麼。

我沒有時間深究原理，先土法煉鋼：把長的那幾筆全部拆開，**一筆記憶只講一件事**。

拆完再測，命中率明顯好轉。

**學到一課**：知識庫裡的一筆，不是「一份文件」，是「一件事」。

---

## 這筆知識，系統說它已經有了

拆成單一事實之後，我士氣大振，繼續往裡面塞。

然後 bot 開始拒絕我。

<br>

```
duplicate detected, memory not stored
```

<br>

我盯著這行訊息看了很久。

不是啊，我明明在存**新的**東西。

排查之後我笑不出來了：我拆出來的單一事實，句型長得一模一樣——

- 「A 是 B」
- 「C 是 D」
- 「E 是 F」

我為了整齊，把每一筆都寫成同一個句式。結果系統覺得這幾筆長得太像，判定是重複的東西，**新的知識直接被擋在門外，寫不進去**。

最諷刺的是：我因為怕搜不到才拆成單一事實，結果拆得太整齊，反而連存都存不進去。

我試的第一招是換嵌入模型，從 `all-MiniLM` 換成 `bge-m3`。有改善，但沒根治，還是會擋。

最後我認輸，直接去把重複判斷的門檻調低——與其讓它幫我擋重複，不如讓它閉嘴，我自己顧。

**學到一課**：把資料寫得太整齊，機器會覺得你在複製貼上。

---

## 答案在第六筆

最後一個惡夢最安靜，安靜到我差點沒發現。

有一次我問了一個問題，bot 回貼了五筆筆記，五筆都不太對。我覺得奇怪，因為我記得我塞過正確答案。

我自己去翻，發現它在**第六筆**。

我的 bot 只貼前五筆。

那筆正確答案，就這樣被切在門外，永遠不會出現在客服眼前。

我把數字從 5 調到 10，那題過了。至於下一題的答案會不會排在第十一筆——我不知道，我只知道那天我沒有再往下想，因為再想下去，這個知識庫就要重做了。

**學到一課**：沒出現的答案，跟不存在沒有兩樣。

---

## 小結

一個禮拜之後，這個知識庫總算堪用了。

我把資料拆細、句式寫得亂一點、回貼從五筆改成十筆——每一招都是繞過去的，沒有一招是真的解決。

至於我那個「年底考績會很好看」的幻想？

<br>

```
salary: no change
```

<br>

沒有人知道我做了這個東西。那個禮拜我唯一收到的回饋，是前輩經過我座位時瞄了一眼螢幕，說了一句「喔，你在玩那個喔」。

好，我在玩那個。

只是我心裡開始有個很不舒服的感覺：我做的每一件事，都是看到症狀就貼一塊膠布。內文太長就拆、寫不進去就調門檻、撈不到就把數字調大。

它現在會動，但我完全不知道它為什麼會動。

也就不知道，它下次為什麼會壞。
