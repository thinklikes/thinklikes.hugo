# 嗨，我是阿清師。

**網站工程師｜後端開發｜AI 應用探索**

> 用工程思維，把複雜問題變成可執行的解決方案。

我是一名喜歡拆解問題的工程師。平常主要在後端開發領域工作，也持續探索 AI 工具如何融入軟體開發與日常工作。

## 我在做什麼

- **後端開發**：PHP、Laravel、MySQL，以及 API 與系統整合。
- **工程實務**：關注程式碼可維護性、資料設計、效能與部署流程。
- **AI 與自動化**：研究 RAG、Coding Agent、Vibe Coding，嘗試把新工具用在真實問題上。

## 這個網站記錄什麼

這裡是我的工程師冒險紀錄。除了技術筆記，也會分享實作過程、遇到的問題，以及那些原本以為很簡單、最後卻花了不少時間才解決的坑。

我不打算把每篇文章都寫成標準答案。比起只記錄結果，我更想留下思考過程，讓未來的自己，也讓正在學習的讀者，能看見一個解法是怎麼慢慢長出來的。
